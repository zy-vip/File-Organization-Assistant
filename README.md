# 文件整理助手（FileTidy）

Windows 桌面文件自动整理工具：配置规则，一键把下载/桌面等杂乱文件夹整理得井井有条。整理前可预览，整理后可撤销。

## 功能

- 按扩展名 / 文件名关键词 / 修改时间（N 天前）自动分类
- 正则表达式条件（Pro）：正则匹配文件名，支持捕获组
- 重命名模板（Pro）：`{name}` `{date:yyyyMMdd}` `{n}` `{1}` 等变量批量重命名
- 规则按顺序匹配，先命中先处理，单个文件单轮只处理一次
- 整理前预览，冲突自动追加序号（报告.pdf → 报告(1).pdf）
- 一次整理一份可撤销日志，支持逐次回退（默认保留最近 10 份，可配置）
- 可选托盘常驻 + 自动整理（新文件到达 3 秒后自动执行）
- 可选开机自启
- 规则列表支持拖拽与按钮排序
- Pro 解锁：离线激活码（14 天 / 20 次试用，试用耗尽后 Pro 功能拦截）
- 配置存于 %AppData%\FileTidy\config.json

## 使用

1. 下载 release 中的 FileTidy.exe（自包含单文件，无需安装任何运行时）
2. 新建规则：填源文件夹、条件（扩展名/关键词/N 天前/正则）、目标文件夹
3. 点「预览结果」确认 → 点「立即整理」
4. 点「撤销上次整理」还原

## Pro 与激活

- 新装即进入试用：14 天 / 20 次整理（任一耗尽即锁定 Pro 功能，免费整理不受影响）
- Pro 功能：正则表达式条件、重命名模板
- 在「设置 → 账户 / 激活」粘贴激活码（`FTID-` 开头）即可永久解锁
- 激活码由开发者通过 FileTidy.LicenseTool 离线生成，激活全程无需联网

## 开发

