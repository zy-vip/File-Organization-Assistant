# 文件整理助手（FileTidy）界面重塑设计文档

- 日期：2026-08-06
- 状态：已确认
- 技术栈：C# / .NET 8 + WPF（net8.0-windows）
- 前提：一期与二期功能已完成（规则整理、预览、执行、撤销、自动监听、托盘、Pro 授权），本次为纯界面重塑

## 1. 目标

把当前"默认 WPF 裸控件"观感升级为**现代浅色（Windows 11 Fluent 语境）**风格：

- 统一的设计系统（配色 / 圆角 / 阴影 / 字体层级 / 图标）
- 页头卡片化，主操作突出蓝紫渐变强调色
- 规则编辑器与设置页从"裸网格"重组为**分组卡片**
- 预览表格状态色化（成功 / 警告 / Pro / 失败 / 未命中）
- 金色「Pro」徽标统一标识付费功能
- **所有绑定与命令原样保留**，低回归风险

## 2. 设计系统

### 2.1 配色（浅色主题）

| 角色 | 值 | 用途 |
|---|---|---|
| 页面底色 | `#F5F6F8` | 窗口背景，与白色卡片形成层次 |
| 卡片/面板底 | `#FFFFFF` | 页头、规则列表、分组卡片 |
| 边框 | `#E5E7EB` | 卡片描边、输入框描边 |
| 主文字 | `#1F2937` | 标题、正文 |
| 次文字 | `#6B7280` | 副标题、说明、占位 |
| 强调色渐变 | `#6366F1 → #8B5CF6` | 主按钮、选中态、Switch 开启态 |
| 成功 | `#10B981` | 预览"将移动"状态 |
| 警告 | `#F59E0B` | 冲突状态、错误横幅底 |
| 错误 | `#EF4444` | 编辑错误红字、失败状态 |
| Pro 徽标 | `#D97706`（琥珀金） | 全部 Pro 功能标识，全局统一 |

### 2.2 形状、字体与图标

- 圆角：按钮 / 输入框 / Switch 轨道 6px，卡片 8px，选中列表项 8px
- 阴影：卡片 `0 1px 2px rgba(0,0,0,.06)`（近似 WPF 用 `DropShadowEffect` 或同色浅描边模拟）
- 字体：系统 Segoe UI；页头标题 18px 加粗，卡片标题 13px 加粗，正文 12px
- 图标：**Segoe MDL2 Assets**（Windows 自带字体，零新增依赖），按钮统一"图标 + 文字"

### 2.3 控件皮肤范围

全部定义在 `App.xaml` 的 `Application.Resources` 资源字典，`MainWindow` 只引用不重复定义：

Button、ToggleButton（**Switch 开关**自定义模板，Win11 风格滑块）、TextBox、ComboBox、CheckBox、ListBox、DataGrid、TabControl、Border（分组卡片统一样式）、StatusBar、ToolTip。

## 3. 窗口布局结构

骨架不变（DockPanel：状态栏底部 + 信息区顶部 + 主区），工具栏升级为**页头卡片**：

```
┌────────────────────────────────────────────────────────────┐
│  ● 文件整理助手                       ⚡预览  ⚡立即整理 ⚡撤销 │   ← 页头卡片
│     免费版·试用剩余X天/X次 · N条规则      [自动整理 Switch]     │      （蓝紫渐变主按钮）
├────────────────────────────────────────────────────────────┤
│  [错误/失败明细横幅 ── 琥珀色卡片，仅出错时出现]           │
├──────────────┬─────────────────────────────────────────────┤
│ 规则列表卡片  │  规则:〈名称〉 编辑错误红字                 │
│ （白底圆角）  │  预览表（常驻, MaxHeight 220, 状态色）      │
│  ＋新建 ↑ ↓  │  标签页: [规则编辑] [设置]                   │
│  ·规则1 ✔    │  分组卡片：文件条件 / 处理动作 / 选项        │
├──────────────┴─────────────────────────────────────────────┤
│ 状态栏：StatusText（保持现有绑定，仅样式美化）              │
└────────────────────────────────────────────────────────────┘
```

- **页头左上**：应用名 + MDL2 字形小图标（如 `\uE8B7` 文件夹）+ 副标题行（授权状态小徽章绑定 `LicenseStateText` + 规则总数绑定 `EditorVms.Count`，均为既有属性）
- **页头右侧**：主操作「立即整理」蓝紫渐变按钮 + 次级「预览结果」「撤销上次」白底按钮 + **自动整理 Switch**
- **Busy 禁用态**：`Busy` 为 true（预览/整理/撤销执行中）时，页头三个操作按钮禁用（绑定 `IsEnabled="{Binding Busy, Converter={StaticResource InverseBool}}"`，新增反向布尔转换器），防重复触发；`Busy` 属性为既有属性
- **错误横幅**：琥珀色卡片（警示语义），错误 / 跳过明细共用，仅 `HasErrorDetails` 时显示
- **左栏规则列表**：白底圆角卡片，新建/上移/下移/删除按钮收进卡片标题行
- 状态栏保持现状内容与绑定（仅 `StatusText`），只做样式美化
- 窗口尺寸保持 900×560，MinWidth 720 / MinHeight 420 不变

## 4. 规则编辑器重排（分组卡片）

现状：10 行裸网格。改为三个分组卡片：

```
┌─ 文件条件 ──────────────────────────────────────────────┐
│ 名称            [____________]                            │
│ 源文件夹        [________________]                        │
│ 目标文件夹      [________________]                        │
│ 扩展名(逗号)    [____________]   关键词(逗号) [_______]    │
│ N天前(0禁用)    [____]           正则表达式(Pro ⬤) [____]  │
│    □ 区分大小写                                          │
└──────────────────────────────────────────────────────────┘
┌─ 处理动作 ──────────────────────────────────────────────┐
│ 动作 [仅移动 ▾ / 移动并重命名(Pro ⬤) ▾]                  │
│ 重命名模板(Pro ⬤) [____________]  ← 选中"移动并重命名"才显示 │
└──────────────────────────────────────────────────────────┘
┌─ 选项 ──────────────────────────────────────────────────┐
│ □ 包含子文件夹   □ 排除目标文件夹树   □ 冲突时自动追加序号 │
└──────────────────────────────────────────────────────────┘
```

- 扩展名与关键词合并为一行两列（短输入，节省纵向空间）
- Pro 功能统一加琥珀金「Pro」小徽章：正则条件、移动并重命名、重命名模板
- 分组卡片标题带小图标：条件=漏斗、动作=齿轮、选项=清单
- 绑定与实时保存逻辑（`UpdateSourceTrigger=PropertyChanged`）不变
- 「重命名模板」行仅在动作选「移动并重命名」时显示，通过 XAML `ElementName` 触发器实现（不改 ViewModel）

## 5. 设置 Tab 重排（分组卡片）

```
┌─ 账户 / 激活（卡片）────────────────────────────────────┐
│  ● Pro 已激活 / 免费版（试用剩余 X 天 / X 次）           │
│  状态色：Pro=蓝紫渐变徽章，试用=琥珀，试用结束=灰        │
│  [激活码输入框] [激活按钮] ← 按钮用渐变强调色            │
│  提示文字（成功绿 / 失败红）                             │
└──────────────────────────────────────────────────────────┘
┌─ 常规（卡片）────────────────────────────────────────────┐
│  [开机自启 Switch]                                        │
│  [新规则默认冲突自动追加序号] CheckBox                    │
└──────────────────────────────────────────────────────────┘
```

- 「自动整理」开关只存在于页头（见第 3 节），设置页不重复放置，避免单一生效入口歧义
- 激活提示的成功/失败颜色由 ViewModel 新增展示属性 `ActivateResultIsError` 判断（`Activate` 已返回 `(ok, message)`，VM 存储结果标志，纯展示层）
- Pro 提示行（免费功能说明）保留在底部灰色小字

## 6. 实现约束

### 6.1 绑定与数据层（红线）

- 所有 `Command` / `Property` 绑定原样保留，只改外观与局部容器
- **ViewModel 层新增（均为纯展示属性）**：
  - `PreviewRow.Status`（`PreviewStatus` 枚举），`RenderPreviews` 一并填充；现有 `Warned` 保留兼容
  - `ActivateResultIsError`（bool）：激活结果是否失败，供提示文字着色（`Activate` 返回值中的 ok 标志写入）
  - `InverseBool` 转换器（App 层静态资源）：供 Busy 禁用态取反
- 页头规则总数直接绑定 `EditorVms.Count`（既有集合，无需新属性）；「重命名模板」行显隐用 XAML `ElementName` 触发器（见第 4 节）
- 行高亮触发器改用新枚举映射：绿=将移动 / 琥珀=冲突 / 金=需解锁Pro / 红=模板错误 / 灰=未命中
- 图标用 Segoe MDL2 Assets、Switch 用 `ToggleButton` 自定义模板：**零新增 NuGet 依赖**

### 6.2 易错点

- 重写 `TextBox` / `ComboBox` 等控件模板时必须保留默认模板内的绑定元素（如 TextBox 的 `PART_ContentHost`），否则输入失效
- 全局样式用 `BasedOn` 链 + 明确 `x:Key` / `TargetType` 层级，避免样式互相覆盖
